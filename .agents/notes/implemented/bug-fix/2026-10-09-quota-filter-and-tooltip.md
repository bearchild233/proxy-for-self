# Agent Note: 配额筛选保留历史身份，环图气泡使用页面浮层

Status: implemented

## Problem

配额查询仅能选密钥，筛选后的数据使账号环图只剩所选密钥，无法反查账号被哪些密钥消耗。历史用量可以包含账号名称快照而没有可登录账号，因此账号管理目录不能作为筛选选项的唯一来源。配额轮询和单独筛选请求原先分别写入同一结果，旧请求可能覆盖新条件。环图宽度只有 156px，长气泡在默认定位下越界并被外层滚动容器裁切。

## Decision

`CatalogFilter` 的 quota 模式提供账号、密钥和关键词入口，类别切换清除旧查询。账号和密钥选择传稳定 ref，继续使用现有服务端 search 与时间范围，不在当前聚合子集上代替服务端查询。`supplementalOptions` 补充本页见过的用量身份快照，同 ref 的当前目录记录优先；下拉框保留已见身份，查询子集不清空候选目录。

所有配额加载走 `loadKeyAccount` 的同一取消与请求序列，后台刷新静默，返回时同时校验序号和当前搜索词。汇总统计与配额请求各自提交结果。

配额 HTML 气泡挂到 body，设置视口内的最大宽度与长文本换行。定位根据原图表边界换算到视口并避让四边，再返回图表坐标；气泡不受卡片的 overflow 裁切。该设置仅作用于配额环图。

## Alternatives considered

- 只复用实时账号目录：改动最小，但只有请求快照、缺少认证记录的历史账号仍无选项。
- 在已加载的聚合行中本地筛选：无需额外请求，但聚合有返回数量上限，不能保证筛选后数值完整；因此筛选仍交给服务端。
- 将气泡限制在环图内部：配置简单，但 156px 无法容纳长名称和指标；页面浮层配合视口约束保留完整内容。

## Consequences

历史身份选项只在本页实例内缓存，不存储认证资料。更换时间范围后仍可选择已见账号；若该范围无记录，显示空结果。尚未加载且不在实时目录中的历史身份仍可通过关键词或完整 ref 查询，补充选项不是完整历史目录接口。

筛选回归覆盖空账号目录、切换清空旧条件、稳定 ref、目录名称优先和乱序响应。气泡与明细滚动通过本地页面定点检查，另运行插件类型检查、相关 lint 与插件构建。

## Runtime compatibility

界面包 `usage-analytics` v0.3.2 沿用 protocol 2、sdk 1、vue-component 和 hostApi 1。热更新目标还必须在宿主 operations 与 usage-analytics 策略中提供并授权 `usage.get.admin.usage.insights.key-account`，且 Rust 管理 API 实现 `GET /api/admin/usage/insights/key-account`。插件包不携带宿主策略或后端程序，不能自行获得这项能力。

原始 v0.3.1 平台策略不包含该能力，而本机测试平台已经补齐；仅查看插件显示版本不足以判定兼容。缺少能力时安装校验应拒绝包并保持旧版服务，补齐宿主与接口后才适用单插件热更新。
