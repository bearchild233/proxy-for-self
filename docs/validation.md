## 出口一致性与缓存诊断（2026-09-30）

- VLESS 分享链接的 `udp=true/false/1/0` 在 Rust 校验、表单往返和 sing-box 配置中一致接受，4 项 Python 配置测试、4 项前端转换测试、5 项 Core 代理测试通过。原链接失败有两个原因：不识别 `udp`；生产 systemd 缺少 `AF_NETLINK`，sing-box 读取接口时启动失败。真实节点在补齐地址族的相同隔离环境中，两项 HTTPS 探测返回 200；不需要 TUN 或 NET_ADMIN。
- 15 项 OpenAI 代理定向测试通过：SSE/WS 账号隔离、HTTP/HTTPS/SOCKS 代理、PAT 导入、令牌刷新/授权交换、额度刷新、模型目录、资料及订阅。新增后三类查询的成功/代理拒绝分支，确认直连 mock 目标没有收到请求。测试内存仓库重建账号遗漏代理和位置已修正；生产仓库从持久化出口加载，解析失败返回错误，不降级直连。
- 调用链审查覆盖自动/手动 token 刷新、额度主动刷新与重试、模型目录、订阅/资料/头像、连接测试、推理 SSE/WS；均使用账号出口。Excel 通过私有 socket 接收账号出口，Worker 显式代理且 `trust_env=False`。更改出口不迁移已经建立的在途连接，新请求使用更新后的配置；切换出口应在账号空闲时进行。
- Native Responses 的 Provider 观测元数据保存 `requestSummary.promptCacheKey`、`sessionId`、`clientSessionId`，请求明细单独展示。前两者用于对照请求缓存键及会话头，第三项保留客户端原始会话标识；OAuth 缺失会话头时使用现有缓存键补齐规则，与发送共享校验。只增加观测，不修改缓存键。集成测试验证发送的缓存键不变且元数据包含标识；旧记录和未取得上游响应的失败请求没有这些新增观测字段。
- 会话亲和优先于轮转；同会话复用/续期及显式 session 优先于逐轮缓存键的测试通过。普通完整历史请求的亲和是软约束，账号繁忙、失效或不在可用范围时可改选；原生 continuation/工具状态仍受 owner 和安全重放约束。未把“优先原账号”描述成永久锁定。
- 相关 Rust 严格 Clippy、前端 lint/build 通过。没有进行浏览器逐页测试。
