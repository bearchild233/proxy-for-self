# 插件平台

## 发布边界

主网关保留 HTTP/WS 推理、鉴权、账号出口、凭据、调度、会话、数据库、额度与计费执行。前端主壳负责登录、导航、主题状态、插件管理与消息桥。功能页面位于 `plugins/<id>/ui`，按包独立构建、安装与回退。

| 分类 | 插件 |
| --- | --- |
| 基础，始终启用 | accounts、groups、keys、usage-analytics、gateway-settings |
| 账号工具 | account-diagnostics |
| 客户端接入 | client-access |
| 功能扩展 | excel-bridge、appearance |
| 运维工具 | proxy-management、backup、pricing |

基础模块不可停用或卸载，在“全部”列表中固定排在可选插件之后；各区内顺序共享保存。拖动先更新本地显示，后台静默保存，失败才提示。

`frontend` 不静态导入功能页面。内置插件声明 `runtime: vue-component`、`hostApi: 1`，输出组件工厂模块；Vue、路由、Pinia、登录/主题状态和基础 UI 组件由主壳统一提供。功能组件和领域辅助代码留在插件包中，单包构建不重编主壳。公共运行接口或新增内核能力的改动需要平台升级。

## 插件内容与运行方式

- 纯页面：静态资源包，不创建后台进程。
- 账号诊断：独立 UI、模板与按需 Python Worker。普通测试经内核固定账号执行并计量；OpenAI 与 xAI 支持自定义文本、模型、推理强度。快速响应头实验仅适用于 OpenAI OAuth。
- 快速检测：一次点击自动准备配套 Cookie/turn-state，再重放一次 hi。宿主在上游收头处关闭响应，不读取 SSE。200 且返回 state 为 29 类；200 未返回为 21 类；失败不分类。标签仅属于发送材料。记录时间、状态、耗时与分类，不发布原始凭据、Cookie、state。分类是用户指定的实验规则。
- Excel：独立 Linux Worker，活动锁覆盖整条请求流。更新关闭新准入、等待活动请求结束，再启动并检查候选；失败恢复旧运行目录及启用状态。排空超时保留现有请求。界面包与 Linux Python 3.10 运行包分开发布，管理器的 Worker 更新使用安装器中已校验的运行包。
- 备份：`worker/policy.py` 独立提供任务准入、计划触发决策和清理筛选。宿主提供经过校验的 Cron 到期事实、数据与备份执行能力，并保留禁止误删最新备份等约束。停用后不领取新任务；已执行的任务完成后停止。对象存储密钥与数据库导出留在内核。
- 出口、定价和主题管理停用后，其已保存运行配置继续生效。
- 模型价格与备份管理位于系统设置分区。定价插件每日 03:00（Asia/Shanghai）同步 models.dev 来源价目，保留人工覆盖及倍率；失败保留价格并在一小时后重试。首次启用安排下一次 03:00，错过计划后启动会补跑一次。后台由受监督的网关任务执行，插件提供可独立更新的计划规则；不依赖浏览器或管理员会话。状态持久化到 `pricing-runtime/status.json`，停用插件后不再领取新同步。

登录辅助续期属于用户明确留待后续的插件，不包含在本批中。

## 包、能力与恢复

清单采用 `protocol: 2`、`sdk: 1`。不可变内容版本由归档 SHA256 标识；资源逐文件校验，拒绝路径穿越、链接、超限资源及未授权能力。基础属性由宿主策略决定，不能由包覆盖。

内置组件插件须由宿主策略授权 `trustedUi`，声明的宿主接口版本必须匹配；包本身不能提升信任。组件直接运行在主应用，不能视为恶意代码沙箱。普通外部插件仍使用不透明来源 iframe 和 CSP。两种界面的业务请求均经命名能力接口；服务端逐次核对插件、版本、能力及实际登录角色，Key 查询保持账号范围约束。新可选插件可以申请已有能力，使用 `/extensions/<id>/...` 路由。

页面和后台任务绑定具体版本。安装切换活动指针，不销毁已有表单；旧版本由 120 秒租约续期保留。通常保留当前版和上一版，活跃租约例外，结束后清理。可选插件停用后关闭旧页面的新 RPC；已启动任务允许排空。

Excel 恢复由独立安装器执行；控制面重启读取操作日志并与安装器状态对齐。无法确认 Worker 状态时关闭新入口，显示失败，不报告假成功。生产服务 `Restart=on-failure`，网关不得 Requires/BindsTo 插件服务。

Python Worker 是管理员安装的受信任代码，不是恶意代码沙箱。UI 沙箱和能力桥不能代替操作系统权限；生产控制面使用独立用户、文件权限及 systemd 资源限制。不要安装来源不明的执行代码。

## 单插件开发

```sh
node scripts/check-plugin.mjs groups
node scripts/build-plugin.mjs groups
python scripts/package-ui-plugin.py groups
```

在插件管理上传 `.build/plugin-releases/groups.tar.gz`，校验后切换；重新打开对应页面使用新版本。无需编译或重启 Rust。新包必须保持现有命名能力合同；需要新宿主能力时先升级平台。

发布包在 `plugin.json` 维护 `version`、带时区的 `releasedAt` 与 `releaseNotes` 字符串数组。管理页展示当前与可回退包的版本、构建标识、发布时间和更新说明；旧包缺失的信息直接标明。回退确认锁定所展示的两个构建，期间若发生更新则拒绝操作并要求刷新，防止回退到未确认的包。回退只切换插件包，不回退业务数据。

仓库提供独立 `plugin-release.yml`，只检查、构建所选插件；Excel 另做干净依赖测试并发布运行包。版本读取该插件 `plugin.json`。工作流是手动触发，不自动部署。

完整平台初始化包由 `scripts/package-plugin-platform.py` 生成，含主壳、控制面和 12 个预装包。首次迁移先安装并验证平台，再切换网关/主壳；未声明已支持协议2的旧更新器拒绝此类整站升级。生产安装步骤见 [平台部署](../deploy/plugin-platform/README.md)。

## 新旧方案成本

前端按功能独立构建，共用一个 Vue 应用；版本、租约、能力接口和恢复逻辑是额外维护成本。代码与样式默认预载，页面数据首次进入时查询，表单和筛选在切页后保留。12 个页面不对应 12 个后台进程，诊断按需启动，备份策略短进程运行，Excel 独立管理。推理流量直接访问 Rust。浏览器组件/数据缓存仍占内存；不能用包体缩小比例代替运行内存实测。

本批仅部署到本机独立测试环境。生产上线、GitHub push 均需用户明确授权。测试结果与入口见 [本机测试](plugin-stage.md)。

### 页面加载

默认静默预载已启用、当前身份可访问插件的代码和样式，同包多页共用一份模块资源。预载不运行页面 setup 或查询业务数据；第一次进入才挂载页面，随后保留组件、表单与筛选，隐藏时暂停业务轮询。逐插件“懒加载”默认关闭；开启后连代码也延迟到首次使用，打开后仍保留页面。开关保存在控制面的 `loading.json`，全站共享。

每个页面实例拥有独立的能力调用上下文和事件通道；异步回调不依赖全局当前插件。所有导航交给主路由；设置页的标题、说明与导航由宿主持有唯一实例。`layout: settings` 内容只占页头下面区域，保存/撤销交给当前活动设置页。

更新只改变后续挂载使用的版本。当前页面继续持有旧版租约及样式，隐藏旧页在目录刷新后移除；失败包不激活，可回退旧包。退出登录清理页面、资源引用和租约。组件卸载清理定时器、事件和样式引用，但浏览器 ESM 模块缓存不保证立即回收，长期多次更新后可通过刷新页面释放旧模块。

组件包首次迁移须同时升级控制面的运行方式校验和前端主壳，打开旧主壳的浏览器需要刷新一次。普通同接口版本的插件更新无需重启网关或控制面。新版继续兼容 iframe 包的安装与回退。
